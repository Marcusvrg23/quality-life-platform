## Inspiração de componentes (sem código copiado)

A landing page (`static/quality_life/home.css`, `home.js` e `ambient.js`) foi escrita do zero em JavaScript puro, CSS e GSAP. Ela segue ideias visuais de componentes do Magic UI, publicados também no 21st.dev. Nenhuma linha desses componentes (React/Tailwind) foi copiada.

| Componente de referência | Ideia aproveitada | Licença do projeto de origem |
| --- | --- | --- |
| Magic UI "Shimmer Button" | Brilho pulsante em gradiente no botão principal | MIT, Copyright (c) Magic UI (https://github.com/magicuidesign/magicui) |
| Magic UI "Border Beam" | Borda luminosa em gradiente que gira nos cards de vidro | MIT, idem |
| Magic UI "Magic Card" | Brilho que acompanha o cursor no card | MIT, idem |
| Magic UI "Particles" | Partículas que derivam e fogem levemente do cursor | MIT, idem |
